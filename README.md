# Ransomeware_Attack_Simulation


## Overview
A controlled cybersecurity demonstration of a Python-based ransomware payload. This project analyzes the operational mechanics of file encryption, backdoor persistence, and system behavior within an isolated lab environment to better inform defensive detection strategies.

> **Disclaimer:** This project was developed strictly for educational and defensive security research purposes in a sandbox environment.

## Key Features
* **File Encryption:** Programmatic text scrambling and encryption across target test directories.
* **Persistence & Execution:** Simulated backdoor persistence mechanism.
* **User Interface & Action:** Graphical prompt simulation and automated system logout payload behavior.

## Tools & Tech Stack
* **Language:** Python 3
* **Environment:** Isolated Linux/VM Lab Environment
* **Concepts:** Cryptographic Operations, Malware Analysis, Behavioral Detection
